# Что находится в каждом файле проекта

Файлы разделены на серверную часть, оформление страниц и автоматические тесты.

## Файлы в корне репозитория

| Файл | Для чего нужен |
| --- | --- |
| [.gitignore](.gitignore) | Указывает, что не загружать в GitHub: рабочую базу, секреты, резервные копии, виртуальное окружение и временные файлы. |
| [README.md](README.md) | Описание проекта, инструкция установки и запуска, настройки и описание API. |
| [ACCEPTANCE.md](ACCEPTANCE.md) | Подробный отчёт о выполнении ТЗ: что проверено и какие результаты получены. |
| [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md) | Этот документ: объяснение назначения всех файлов репозитория. |
| [main.py](main.py) | Точка запуска приложения. Создаёт приложение и запускает сервер Waitress. |
| [requirements.txt](requirements.txt) | Точка входа для установки через `pip install -r requirements.txt`. Подключает проект и его зависимости из `pyproject.toml`. |
| [pyproject.toml](pyproject.toml) | Метаданные проекта, минимальная версия Python `>=3.11` без верхнего ограничения и точные версии библиотек. Установщик отклоняет неподходящий Python. |
| [check_python.py](check_python.py) | Проверяет версию Python без сторонних библиотек. Выводит понятную ошибку на версии ниже 3.11; вызывается до загрузки приложения. |
| [setup.py](setup.py) | Запускает ту же проверку версии во время установки, до разрешения зависимостей, чтобы вместо непонятной ошибки Flask показать требование Python 3.11+. |

## Папка `olympiad` — серверная логика

| Файл | Что делает |
| --- | --- |
| [__init__.py](olympiad/__init__.py) | Создаёт и настраивает приложение Flask. Обрабатывает регистрацию, вход, выход, открытие страниц и запросы API. Получает данные для профиля, каталога, истории и рейтинга. |
| [db.py](olympiad/db.py) | Создаёт таблицы SQLite, переносит данные старой версии, сохраняет попытки и начисляет баллы. Защищает от повторного начисления при одновременных запросах. Содержит обслуживание старых данных с резервным копированием. |
| [security.py](olympiad/security.py) | Проверяет авторизацию и CSRF-токены, ограничивает частоту запросов, создаёт постоянный секретный ключ сессий. |
| [formatting.py](olympiad/formatting.py) | Выбирает русские окончания: «1 балл», «2 балла», «5 баллов». Оформляет даты по московскому времени и подготавливает текст условий к показу. |
| [seeds.py](olympiad/seeds.py) | Содержит 23 стартовые задачи: условия, сложность, категории, исходные данные и правильные ответы для серверной проверки. |

## Папка `static` — оформление и поведение интерфейса

| Файл | Что делает |
| --- | --- |
| [site.css](static/site.css) | Основное оформление сайта: цвета, шапка, кнопки, формы, таблицы, профиль, страницы авторизации и адаптация под размер экрана. Содержит стили светлой и тёмной тем. |
| [catalog.css](static/catalog.css) | Оформление каталога: карточки задач, цветные рамки сложности, звёздочки и выпадающие фильтры. |
| [app.js](static/app.js) | Управляет выпадающими фильтрами: открытием, выбором вариантов, клавиатурой и отправкой формы фильтрации. |
| [theme.js](static/theme.js) | Переключает светлую и тёмную темы, сохраняет выбор в браузере и восстанавливает его при открытии страниц. |

## Папка `templates` — HTML-шаблоны страниц

Сервер подставляет в шаблоны данные пользователя, задачи и результаты.

| Файл | Что отображает |
| --- | --- |
| [base.html](templates/base.html) | Общую основу страниц: шапку, навигацию, переключатель темы, сообщения и подключение CSS/JavaScript. |
| [index.html](templates/index.html) | Главную страницу: приветствие, статистику платформы, разделы задач и рейтинг. |
| [tasks.html](templates/tasks.html) | Каталог задач с фильтрами по сложности и категории. |
| [task.html](templates/task.html) | Отдельную задачу: условие, исходные данные, формат ответа, форму отправки и последние попытки. |
| [profile.html](templates/profile.html) | Личный кабинет: логин, баллы, решённые задачи, число попыток и процент правильных ответов. |
| [history.html](templates/history.html) | Историю попыток текущего пользователя с переключением страниц. |
| [leaderboard.html](templates/leaderboard.html) | Таблицу лидеров, первые три места и список всех участников. |
| [login.html](templates/login.html) | Форму входа в аккаунт. |
| [register.html](templates/register.html) | Форму регистрации. |
| [error.html](templates/error.html) | Страницы ошибок, например при открытии несуществующей задачи. |
| [_auth.html](templates/_auth.html) | Общий полноэкранный макет для входа и регистрации. |
| [_attempts.html](templates/_attempts.html) | Повторно используемую таблицу попыток: задача, дата, ответ и результат. |
| [_icons.html](templates/_icons.html) | Набор SVG-значков для интерфейса. |
| [_task_meta.html](templates/_task_meta.html) | Звёздочки, соответствующие сложности задачи. |
| [_theme_toggle.html](templates/_theme_toggle.html) | Кнопки «Светлая» и «Тёмная». |

Файлы с `_` в начале — вспомогательные части, которые вставляются в другие
шаблоны. Например, таблица из `_attempts.html` используется в профиле,
истории и на странице задачи.

## Папка `tests` — автоматические проверки

| Файл | Что проверяет |
| --- | --- |
| [__init__.py](tests/__init__.py) | Служебный файл, позволяющий Python воспринимать папку тестов как пакет. |
| [test_backend.py](tests/test_backend.py) | Регистрацию, авторизацию, баллы, историю, разделение пользователей, защиту API, параллельные запросы и сохранность данных. |

| [test_python_version.py](tests/test_python_version.py) | Проверяет отказ на Python ниже 3.11, допуск новых версий без верхней границы и остановку до загрузки приложения. |

## Файлы, создаваемые при запуске

Эти файлы не входят в репозиторий:

- `database.db` — рабочая база с пользователями, задачами, попытками и прогрессом.
- `instance/secret.key` — постоянный ключ для подписи пользовательских сессий.
- `backups/` — локальные резервные копии.
- `.venv/` — установленные Python-библиотеки и интерпретатор окружения.

При первом запуске приложение само создаёт базу и добавляет 23 задачи.
Готовую базу скачивать или вручную изменять исходники для запуска не нужно.

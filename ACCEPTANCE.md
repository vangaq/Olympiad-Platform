# Проверка соответствия техническому заданию

Дата: 18 октября 2026 года. Проверена финальная локальная версия перед публикацией.

Итог: критических несоответствий ТЗ не обнаружено. Все 24 автоматических теста
прошли в отдельном виртуальном окружении с зависимостями из `requirements.txt`.
Время финального прогона — 13,212 с. Рабочая база пользователей в проверках
не использовалась: автоматические тесты создают временные базы; для браузера
запускалась отдельная копия сервера с собственной базой.

прежний контракт: создание аккаунта без автоматического входа.

- Список включает зарегистрированных пользователей без баллов.
- Сортировка: количество баллов по убыванию, затем нормализованный логин.

- Проверены пользователи с разным количеством баллов и изоляция их прогресса.

## 3. Сервер, база и защита API

- Работают HTML-интерфейс, Flask-сервер и SQLite.
- Проверка и начисление баллов выполняются на сервере.
- Подстановка `points`, `user_id`, `correct`, `solved`, `is_admin` и других
  неподдерживаемых полей отклоняется. Изменить чужие баллы через API нельзя.
- Закрытые маршруты требуют сессию; изменяющие запросы требуют CSRF.
- Проверены некорректные типы/размеры данных, повторяющиеся поля формы,
  отсутствующие задачи, неверные фильтры и номера страниц.
- Проверены экранирование XSS, отсутствие исполнения присланного кода,
  невозможность подделать сессию старым публичным ключом и отзыв сессий
  после локального сброса пароля.
- Ограничения частоты запросов сохраняются между перезапусками.
- База и ключ сессий сохраняются на диске. HTTP-тест останавливает всё дерево
  процесса сервера, проверяет закрытие порта и запускает сервер заново.

При дополнительной проверке исправлена остановка HTTP-теста в Windows:
завершение только venv-лаунчера могло оставить дочерний сервер и заблокированный
лог. Теперь перед повторным запуском завершается всё дерево тестового процесса.

## 4. Действия при приёмке

Все 12 сценариев из раздела 4 ТЗ покрыты автоматическими проверками:
два пользователя, вход, правильные/неправильные ответы, баллы, повтор,
история, рейтинг, сохранность, изоляция, неверные данные, прямые запросы
с поддельными параметрами и перезапуск сервера.

В браузере дополнительно выполнены регистрация с переходом на главную,
неверная/верная/повторная отправка, просмотр профиля и истории, фильтрация
каталога по средней сложности (9 задач), смена темы, перезагрузка страницы
и выход. Тема сохраняется между переходами и после выхода. В проверенном
окне не обнаружены ошибки JavaScript или горизонтальное переполнение страницы.

## 5. Комплект сдачи и запуск

- Полный исходный код, шаблоны, статические файлы, тесты и README включены
  в репозиторий.
- В отдельную папку скопированы только исходники, без рабочей базы и секретов.
- Создано новое виртуальное окружение; зависимости установлены по инструкции
  README с PyPI. `pip check` не обнаружил конфликтов в рабочем окружении.
- Чистый запуск автоматически создал постоянный ключ сессий и SQLite с
  23 задачами и 0 пользователями. Изменять исходники для запуска не потребовалось.
- Проверенная среда: Windows, Python 3.13. Команды запуска для Linux/macOS
  также приведены в README; отдельно в этих ОС не запускалось.
- Рабочая база, резервные копии, `.venv`, `instance` и секреты исключены из Git.

Запуск всех проверок:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

# 🏆 Olympiad Training Platform

Платформа для подготовки к олимпиадам по программированию с PvP соревнованиями.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск

```bash
python main.py
```

### 3. Открыть в браузере

Перейдите по адресу: **http://localhost:5000**

## 🔑 Демо-аккаунты

- **Администратор**: `admin` / `admin123`
- **Новые пользователи**: можно зарегистрироваться на странице `/register`

## 📝 Добавление новых задач (для админов)

### Способ 1: Через админ-панель (рекомендуется)

1. Войдите как администратор (admin / admin123)
2. Перейдите в "⚙️ Админка"
3. Заполните форму добавления задачи:
   - **Название** — краткое название задачи
   - **Описание** — подробное условие
   - **Сложность** — 1 (легкая), 2 (средняя), 3 (сложная)
   - **Категория** — math, strings, arrays и т.д.
   - **Формат входных данных** — что подается на вход
   - **Формат выходных данных** — что нужно вывести
   - **Пример входа/выхода** — для понимания
   - **Тесты** — входные данные (по одному тесту на строку)
   - **Ответы** — ожидаемые выходы (соответствуют тестам)

### Способ 2: Редактированием main.py

Добавьте задачу в список `sample_tasks` в функции `init_db()`:

```python
{
    'title': 'Название задачи',
    'description': 'Описание условия',
    'difficulty': 1,  # 1, 2 или 3
    'input_format': 'Что на входе',
    'output_format': 'Что на выходе',
    'sample_input': 'пример входа',
    'sample_output': 'пример выхода',
    'test_cases': json.dumps([
        {'input': 'тест1', 'output': 'ответ1'},
        {'input': 'тест2', 'output': 'ответ2'},
    ]),
    'category': 'math'  # или strings, arrays
}
```

Затем удалите `database.db` и перезапустите сервер — задачи добавятся автоматически!

### Способ 3: Напрямую в БД (для продвинутых)

## 🐛 Возможные проблемы

### Порт 5000 занят
```bash
# Найти процесс
lsof -i :5000
# Или на Windows
netstat -ano | findstr :5000

# Изменить порт в main.py (строка с socketio.run)
socketio.run(app, host='0.0.0.0', port=5001, ...)
```

### Ошибки при установке зависимостей
```bash
# Обновить pip
pip install --upgrade pip

# Установить зависимости по отдельности
pip install flask flask-socketio flask-login werkzeug eventlet
```

### Обновление задач (после изменения main.py)
Если вы добавили новые задачи в код:
```bash
# 1. Остановите сервер (Ctrl+C)
# 2. Удалите старую базу данных
del database.db  # Windows
rm database.db   # Linux/Mac

# 3. Перезапустите сервер — задачи добавятся автоматически!
python main.py
```

## 📱 Запуск в PyCharm

1. Откройте папку `olymp_platform` в PyCharm
2. Установите зависимости: `pip install -r requirements.txt` в терминале
3. Правый клик на `main.py` → Run
4. Откройте http://localhost:5000 в браузере

## 🔧 Технологии

- **Backend**: Flask + Flask-SocketIO
- **База данных**: SQLite (встроенная, не требует установки)
- **Frontend**: HTML + CSS + JavaScript
- **WebSocket**: Для real-time PvP соревнований
